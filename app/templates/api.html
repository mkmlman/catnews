API

Every digest as JSON, Markdown, or RSS — no auth needed.

Endpoints

Paths are relative to the site root ({{ base_path }} on Pages, http://localhost:8000 on the dev server).

{{ base_path }}/api/sourcesAll snapshots, each with its stories
{{ base_path }}/api/sources/<source>Latest snapshot for a source (hn, arxiv, github, registerspill)
{{ base_path }}/api/sources/<source>/<YYYY-MM-DD>A specific day's snapshot for a source
{{ base_path }}/api/digestLatest story from each source, combined in source order
{{ base_path }}/api/storiesEvery story, optionally filtered with ?source=hn
{{ base_path }}/api/statsSite statistics (totals, editions, by source)
{{ base_path }}/api/stories.mdAll stories as a Markdown document
{{ base_path }}/feed.rssRSS 2.0 feed of the latest combined digest

Static vs live

On GitHub Pages, the API is a static mirror: api/sources.json, api/stories.json, api/digest.json, api/stats.json, api/stories.md, and feed.rss are generated at build time, so there is no server. The live dev server (uvicorn app.main:app) additionally serves the per-source routes (/api/sources/<source> and /api/sources/<source>/<date>) and the rendered archive pages (/archive/<source>/<date>/).
