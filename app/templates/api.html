Serving

  
On GitHub Pages the API is a static mirror — api/sources.json, api/sources/<source>.json, api/stories.json, api/search.json, api/digest.json, api/stats.json, api/trends.json, api/fetch-status.json, api/stories.md, and feed.rss are written at build time, so the deployed site has no server.

  
The dev server (uvicorn app.main:app) serves everything dynamically, including the per-source routes /api/sources/<source>, /api/sources/<source>/<date>, and the rendered archive pages /archive/<source>/<date>/.






  
Example

  
$ curl {{ base_url }}/api/sources/hn | head
{
  "source": "hn",
  "date": "2026-08-03",
  "stories": [
    { "source": "hn", "title": "Diátaxis", "url": "https://diataxis.fr/" }
  ]
}
