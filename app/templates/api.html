API

The digest as JSON, Markdown, or RSS — no auth required.

Endpoints

  • GET {{ base_path }}/api/sources

    All snapshots, each with its stories

  • GET {{ base_path }}/api/sources/<source>

    Latest snapshot for a source — hn, arxiv, github, registerspill

  • GET {{ base_path }}/api/sources/<source>/<date>

    A specific day's snapshot for a source (YYYY-MM-DD)

  • GET {{ base_path }}/api/digest

    Latest story from each source, combined in source order

  • GET {{ base_path }}/api/stories

    Every story, optionally filtered with ?source=hn

  • GET {{ base_path }}/api/stats

    Site statistics — totals, editions, by source

  • GET {{ base_path }}/api/stories.md

    All stories as a single Markdown document

  • GET {{ base_path }}/feed.rss

    RSS 2.0 feed of the latest combined digest

Static vs live

On GitHub Pages the API is a static mirror: api/sources.json, api/stories.json, api/digest.json, api/stats.json, api/stories.md, and feed.rss are generated at build time — there is no server. The dev server (uvicorn app.main:app) additionally serves the per-source routes (/api/sources/<source>, /api/sources/<source>/<date>) and the rendered archive pages (/archive/<source>/<date>/).

Example

$ curl {{ base_url }}/api/sources/hn | head

  "date": "2026-08-03",
  "stories": [

  ]
