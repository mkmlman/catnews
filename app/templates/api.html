API

The digest as JSON, Markdown, or RSS — no auth required.

Snapshots

  • GET {{ base_path }}/api/sources

    All snapshots, each with its stories.

  • GET {{ base_path }}/api/sources/<source>.json

    The latest snapshot for a source — {{ source_tags | join(", ") }}.

  • GET {{ base_path }}/api/sources/<source>/<date>

    A specific day's snapshot for a source (YYYY-MM-DD).

Digest & feed

  • GET {{ base_path }}/api/digest

    The latest story from each source, interleaved round-robin.

  • GET {{ base_path }}/api/stories

    Every story across all snapshots — filter with ?source=hn.

  • GET {{ base_path }}/api/search.json

    Compact, deduplicated records used by archive search.

  • GET {{ base_path }}/api/stories.md

    All stories as a single Markdown document.

  • GET {{ base_path }}/feed.rss

    RSS 2.0 feed of the latest combined digest.

Stats

  • GET {{ base_path }}/api/stats

    Site statistics — totals, snapshots, breakdown by source.

  • GET {{ base_path }}/api/trends

    Story counts per source, bucketed by ISO week.

  • GET {{ base_path }}/api/fetch-status.json

    Build-time source freshness and fetch diagnostics.

Serving

On GitHub Pages the API is a static mirror — api/sources.json, api/sources/<source>.json, api/stories.json, api/search.json, api/digest.json, api/stats.json, api/trends.json, api/fetch-status.json, api/stories.md, and feed.rss are written at build time, so the deployed site has no server.

The dev server (uvicorn app.main:app) serves everything dynamically, including the per-source routes /api/sources/<source>, /api/sources/<source>/<date>, and the rendered archive pages /archive/<source>/<date>/.

Example

$ curl {{ base_url }}/api/sources/hn | head
{
  "source": "hn",
  "date": "2026-08-03",
  "stories": [
    { "source": "hn", "title": "Diátaxis", "url": "https://diataxis.fr/" }
  ]
}
